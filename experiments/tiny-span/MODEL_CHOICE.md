# Model shortlist for exact source spans

Google BERT Tiny was the right first experiment for a 10 MB model-artifact budget and a 25 ms p95 added CPU budget. It scores source offsets and abstention in a single batch and supports several fields on the same line. The LoRA span pilot recovered more exact validation emissions than full fitting or fitting just the boundary head. The measured model artifacts fit the size budget. The standalone research runtime exceeds it, and the quality and coverage gates still govern any proposal to integrate the model. [Pilot results and runtime accounting](PILOT.md).

## Bounded decoder comparison

A later decoder experiment could test whether generative context helps choose among source spans that confuse the boundary head. A deterministic enumerator would assign small integer IDs to eligible source spans and retain the note identity, zero-based line, and Unicode codepoint offsets for each. The decoder would receive a bounded candidate table from the recording and use a grammar that accepts a fixed row of four slots in artist, date, venue and city order. Each slot would allow only that role's enumerated IDs or `null`. Cap the prompt and output, abstain if the input exceeds the allowed context, and fail closed on incomplete decoding, duplicate selections of the same source range, or IDs missing from the original table. The application would recover the quote by slicing the normalized source and validate it with the same date, ambiguity, review-state and field-difference checks. A grammar establishes structure and range membership. Precision still depends on selecting the correct source span, and candidate enumeration puts an upper bound on recall. [llama.cpp grammar format and constraints](https://github.com/ggml-org/llama.cpp/blob/master/grammars/README.md).

Measure the exact deployment artifact with the tokenizer, grammar, validation and proposal overlay on CPU. Include all prompt and decode work in warm added latency, report cold startup separately, and count both model files and runtime dependencies. Use the same grouped source splits and the same predeclared exact-span and abstention gates; compare a frozen no-adaptation decoder, LoRA and QLoRA only after confirming deployment fits the intended size limit. Under the current limit the decoder is a research comparison and the fitted encoder already provides the smaller measured reference.
