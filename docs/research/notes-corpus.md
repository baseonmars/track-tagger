# Synthetic concert-notes corpus

Frozen at 2026-10-24 12:48:25 UTC for an independent parser baseline. The test fixture contains 200 synthetic note cases derived from 200 distinct inspected Internet Archive recordings. Original note bytes and all media stay outside this repository. The [source manifest](notes-corpus-sources.json) records each inspected note URL, SHA-256 of its original bytes, recording identity, show date, artist and split. For three recordings with a second inspected note, it also records the second URL and hash.

The corpus has 140 development cases and 60 held-out cases. The 192 main cases contribute 134/58; eight Grateful Dead cases contribute 6/2. Twenty performing acts appear, with at most 38 recordings from any one act. The main recordings cover 2010-2026; the Grateful Dead cases add 1970, 1980 and 1990. Across the main cases, 10 notes use Windows-1252 with non-ASCII synthetic characters. Section headings, leading numbers, dated file tokens, unsupported filename forms, medley punctuation, duration columns, blank numbered rows, duplicate notes and source mismatches are represented. A `review` value means the synthetic evidence itself is ambiguous or incomplete; unsupported identifier families are not converted to positional song mappings.

The source-derived excerpt normally retains three to six track rows, their numbering and structural punctuation. Song names, people, venue names and cities are fictional. Source dates remain when supported by inspected notes. Original filename shapes are retained where practical; source names with embedded song or personal words are simplified to synthetic basenames, and those changes are stated in case explanations. Every case specifies parsed note titles separately from per-file mappings. Duration and footnote text inside a numbered title is part of its exact expected title. Technical duration report rows are companion evidence, never song titles.

Known archive identity and note discrepancies are kept in source provenance: `rads2005-05-12` notes state 2011-05-12; `sts9-2032-12-30.ClarkMix.flac` notes state 2023-12-30; `rads2011-04-18.sbd.v3` notes state 2011-03-18; `rad2011-01-28.rad2011-01-28sbdOZ` notes state 2011-11-28. Other item and note date differences occur for `311-2023-09-30`, `311-2024-09-27`, `311-2022-09-21.Beyermc930`, `bt2024-07-09`, and `bt2022-10-20.yt.flac16`; no date was silently inferred from track position. These discrepancies should be reviewed against the original source URLs when diagnosing an individual case.

The independent source generator verified SHA-256 against locally downloaded original note bytes. The eight Grateful Dead cases were independently reviewed before integration. No production parser output was used to author expectations.
